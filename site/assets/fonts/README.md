# Bundled fonts

Latin subsets from Google Fonts, bundled so the app renders offline.
All three are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org).

| File | Family | Use |
|---|---|---|
| `bricolage-grotesque.woff2` | Bricolage Grotesque (variable opsz/wght), © The Bricolage Grotesque Project Authors | display: titles, wordmark |
| `figtree.woff2`, `figtree-italic.woff2` | Figtree (variable wght), © The Figtree Project Authors | body text |
| `martian-mono.woff2` | Martian Mono (variable wdth/wght), © The Martian Mono Project Authors | readouts: codes, sizes, labels |
